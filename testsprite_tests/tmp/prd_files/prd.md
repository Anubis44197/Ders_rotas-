# Ders Rotası - Product Requirement Document (PRD)

## Project Overview
Ders Rotası is a comprehensive web-based curriculum planning and academic analysis application designed for students and parents. It helps students track their study hours, syllabus, homework progress, and exam scores, while offering a passcode-locked parent view for deeper analytics and planning.

## Key Features

### 1. Student Dashboard (Child View)
- View daily study rotas, courses, and time allocations.
- Log study sessions, question counts, and correctness rates.
- Interactive checklist for tasks and syllabus tracking.
- Weekly progress visualization.

### 2. Passcode-Locked Parent Dashboard (Parent View)
- Access locked behind a simple local lockscreen (`ParentLockScreen`).
- In-depth performance analytics using Recharts.
- Curriculum and study rota customization.
- Intelligent replanning engine to adjust study schedules based on performance.
- Multi-dimensional academic risk model (analyzing task failure, cognitive loads, and consistency).

### 3. Analytics & Graph Center
- Recharts visualizations for subject distributions, correctness rates, and study duration metrics.
- Comprehensive metrics showing active study durations, total logged tasks, and current syllabus completion rates.

### 4. Rota Planning Engine
- Dynamic curriculum generator loaded with custom educational blocks.
- Real-time study load calculation.
- Automated suggestions for pacing and adjustments.
